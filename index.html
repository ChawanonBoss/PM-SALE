ซื้อขายทั้งหมด

ซื้อขาย — สถานะดูจากรายการสินค้าแต่ละบรรทัด: ยังไม่มีรายการที่ดำเนินการ = รอดำเนินการ, ดำเนินการบางส่วน = กำลังดำเนินการ, ครบทุกรายการ = ดำเนินการแล้ว · เลือกสินค้าจากโกดัง เมื่อบันทึกเป็น "ดำเนินการแล้ว" ระบบตัดจำนวนและ Serial ออกจากโกดังให้ · ช่อง "สถานะงาน" ติ๊กเองไม่ได้ ระบบติ๊กให้เมื่อแนบรูปภาพจริงเท่านั้น (เว้นว่างถ้ารายการนี้ไม่ได้เลือกชุดรูปนั้นตอนสร้าง) · กด ⚙ ที่หัวตารางเพื่อเลือกว่าจะแสดงคอลัมน์ไหนบ้าง (มีผลเฉพาะเบราว์เซอร์นี้)

เลขที่เอกสารชื่องานลูกค้า เลขที่ POวันที่สั่งซื้อรายการสถานะ สถานะงาน สร้างโดย
รูปภาพอุปกรณ์รูปภาพงานติดตั้ง

โครงการทั้งหมด

โครงการ — สถานะคำนวณอัตโนมัติ: ก่อนวันเซ็นสัญญา หรือยังไม่ได้ระบุข้อมูลใน Action Plan = รอดำเนินการ, อยู่ในช่วงสัญญาและมีแผนแล้ว = กำลังดำเนินการ, หลังวันสิ้นสุด = สิ้นสุดสัญญาโครงการ · เลือกอุปกรณ์จากโกดังเหมือนการซื้อขาย และกด "แผนงาน" เพื่อวางขั้นตอนใน Action Plan · ตัวกรอง "งวดงาน" อ้างอิงจากงวดที่ยังไม่ได้ส่ง (หรืองวดสุดท้ายถ้าส่งครบแล้ว) ของแต่ละโครงการ · ช่อง "สถานะงาน" ติ๊กเองไม่ได้ ระบบติ๊กให้เมื่อบันทึกแผนดำเนินงาน/รูปภาพจริงเท่านั้น · กด "คอลัมน์" เพื่อเลือกว่าจะแสดงคอลัมน์ไหนบ้าง (มีผลเฉพาะเบราว์เซอร์นี้)

เลขที่เอกสารงวดงานชื่อโครงการลูกค้า เลขที่สัญญาระยะเวลารายการสถานะ สถานะงาน สร้างโดย
แผนการดำเนินงานรูปภาพอุปกรณ์รูปภาพงานติดตั้ง

แผนดำเนินการรายโครงการ

แต่ละโครงการมีแผนดำเนินการของตัวเอง — กดที่โครงการเพื่อเปิดแผนของโครงการนั้น

สัปดาห์นับตามวันที่ในเดือน: วัน 1–7 = สัปดาห์ที่ 1, 8–14 = 2, 15–21 = 3, 22–28 = 4, 29 ขึ้นไป = 5 · แถบสีจะเรียงต่อจากสัปดาห์ของวันเริ่มต้นไปจนถึงสัปดาห์ของวันสิ้นสุด (ส่วนสีเข้มคือความคืบหน้า) · ลากแถบเพื่อย้าย, ลากขอบซ้าย/ขวาเพื่อปรับความยาว (เป็นรายสัปดาห์), ลากบนแถวที่ยังไม่มีวันที่เพื่อสร้างแถบ · ติ๊กช่อง ✓ หน้าสุดของแถวเมื่อดำเนินการแล้ว (ความคืบหน้าคำนวณจากจำนวนที่ติ๊ก)

ข้อมูลมาจากช่อง "สถานที่" และ "การรับประกัน (เดือน)" ในฟอร์มเพิ่มรายการ — โครงการนับจากวันที่สิ้นสุดโครงการ, ซื้อขายนับจากวันที่สั่งซื้อ

เลขที่เอกสารซื้อขาย/โครงการ · ลูกค้าประเภทสถานที่ติดตั้ง / ส่งสินค้าเริ่มรับประกันประกัน (เดือน)หมดประกันสถานะ
