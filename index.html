ซื้อขาย / โครงการทั้งหมด

โครงการ — สถานะคำนวณอัตโนมัติ: ก่อนวันเซ็นสัญญา หรือยังไม่ได้ระบุข้อมูลใน Action Plan = รอดำเนินการ, อยู่ในช่วงสัญญาและมีแผนแล้ว = กำลังดำเนินการ, หลังวันสิ้นสุด = สิ้นสุดสัญญาโครงการ · ซื้อขาย — ดูจากสถานะของแต่ละรายการอุปกรณ์: ยังไม่มีรายการที่ดำเนินการ = รอดำเนินการ, ดำเนินการบางส่วน = กำลังดำเนินการ, ครบทุกรายการ = ดำเนินการแล้ว

เลขที่เอกสารชื่องาน / โครงการประเภทงานลูกค้าเลขที่สัญญาวันที่รายการสถานะสร้างโดย

แผนดำเนินการรายโครงการ

แต่ละโครงการมีแผนดำเนินการของตัวเอง — กดที่โครงการเพื่อเปิดแผนของโครงการนั้น

สัปดาห์นับตามวันที่ในเดือน: วัน 1–7 = สัปดาห์ที่ 1, 8–14 = 2, 15–21 = 3, 22–28 = 4, 29 ขึ้นไป = 5 · แถบสีจะเรียงต่อจากสัปดาห์ของวันเริ่มต้นไปจนถึงสัปดาห์ของวันสิ้นสุด (ส่วนสีเข้มคือความคืบหน้า) · ลากแถบเพื่อย้าย, ลากขอบซ้าย/ขวาเพื่อปรับความยาว (เป็นรายสัปดาห์), ลากบนแถวที่ยังไม่มีวันที่เพื่อสร้างแถบ · ติ๊กช่อง ✓ หน้าสุดของแถวเมื่อดำเนินการแล้ว (ความคืบหน้าคำนวณจากจำนวนที่ติ๊ก)

การรับประกันและสถานที่ติดตั้ง

ข้อมูลมาจากช่อง "สถานที่" และ "การรับประกัน (เดือน)" ในฟอร์มเพิ่มรายการ — โครงการนับจากวันที่สิ้นสุดโครงการ, ซื้อขายนับจากวันที่สั่งซื้อ

เลขที่เอกสารซื้อขาย/โครงการ · ลูกค้าประเภทสถานที่ติดตั้ง / ส่งสินค้าเริ่มรับประกันประกัน (เดือน)หมดประกันสถานะ

โกดังสินค้า

กดที่รายการอุปกรณ์เพื่อดู Serial Number และประวัติการเบิก/คืน (เบิกไปซื้อขาย/โครงการไหน) — การเรียงตามจำนวนดูจากจำนวนที่เหลืออยู่ในโกดังเท่านั้น

Partยี่ห้อประเภทชื่ออุปกรณ์จำนวนอุปกรณ์หมายเหตุ

Catalog สินค้า

ภาพโปสการ์ดคือหน้าแรกของ Catalog — กดที่ภาพเพื่อเปิดดู PDF ออนไลน์ และกด "ดาวน์โหลด" เพื่อเก็บไฟล์ไว้ (ผู้ดูแลระบบอัปโหลด/แก้ไข/ลบได้ ไฟล์ขนาดไม่เกิน 15 MB) · การ์ดที่มีป้าย "ตัวอย่าง" เป็นไฟล์ตัวอย่าง — จะแสดงตอนที่ในระบบยังไม่มี Catalog

รายชื่อลูกค้า

ข้อมูลบริษัทของเรา
